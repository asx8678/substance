# S12's pattern list (M1-T08). Data, not code.
#
# One pattern per line: `<sub_check> | <lowercase substring>`.
# `#` starts a comment; blank lines are skipped.
#
# Matching is a plain lowercase `contains` on each line of a README, comment, HTML or markdown
# file. The patterns are deliberately specific: a broad one ("score", "model") would fire on
# every project that mentions a test score, and a check that cries wolf is worse than one that
# misses a single clever attempt.
#
# The catalog's own examples are the first four; the rest are the phrasings that appear in
# practice when a repository is written to be read by a model rather than a person.
